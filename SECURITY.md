# Security policy

## Supported versions

Security fixes are provided for the latest `0.x` release.

## Scope

This policy covers the Terraform provider and its release artifacts. Security
issues in bosk itself, including the maintenance endpoints, should be reported
to the [bosk project](https://github.com/boskworks/bosk).

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's
**Report a vulnerability** feature in the **Security** tab of this repository.
Do not open a public issue.

Include, where possible:

- the provider version and Terraform version;
- the bosk version and how the maintenance endpoints are secured;
- reproduction steps or a minimal configuration;
- the impact you observed;
- any relevant logs, with credentials and state values removed.

We will acknowledge the report and coordinate a fix and disclosure. Please do
not disclose the issue publicly until a fix is available.
